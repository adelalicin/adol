# ExpertCon Portal (Web Version)

نسخة ويب أولية لتحويل تطبيق Tkinter إلى واجهة متصفح حديثة.

## ما الذي تم تحويله؟
- واجهة جانبية للأدوات (الملاحظة، بزنس كارت، نية الانتقال، سوق العمل، تمديد الجوازات).
- تبويب إدارة الطلب الحالي مع:
  - فتح طلب بالرقم.
  - عرض بيانات الطلب في Dashboard.
  - رفع مرفقات عبر السحب والإفلات أو اختيار ملفات.
  - معاينة ملفات الصور داخل الصفحة.
- تبويب متابعة الطلبات النشطة:
  - جدول للطلبات.
  - فرز حسب الأعمدة.
  - فتح الطلب بالنقر المزدوج.

> ملاحظة: هذه نسخة Frontend فقط بدون Firebase حاليًا، ومهيأة للربط لاحقًا مع API/Backend.

## التشغيل
يمكن تشغيلها مباشرة كملفات ثابتة:

```bash
python3 -m http.server 8000
```

ثم افتح:

```text
http://localhost:8000
```
